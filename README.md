# 译读

一个面向英文技术文章的 Chrome 右侧边栏翻译扩展。原网页保持不变；滚动原文时，右侧译文会同步跟随。译读按阅读位置渐进翻译标题、各级标题、正文、列表和引用，并在中文侧保留加粗、下划线、链接、强调及行内代码等语义格式。翻译结果缓存在当前浏览器中，AI 专有名词高亮默认关闭。表格、多列卡片和轮播组件不在右侧拆散翻译，仍完整保留于原网页。

## 本地使用

1. 打开 `chrome://extensions`，启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本项目目录。
3. 打开扩展详情页的“扩展程序选项”，填写 DeepSeek API Key。
4. 进入英文文章页面，点击工具栏中的扩展图标，Chrome 会在右侧打开译读。

API Key 仅保存在当前浏览器的本地扩展存储中。图片、图表、视频和交互组件保留在原网页，不进行 OCR 或复制翻译。

## 划词翻译与解释

在原网页中选中英文，会出现“翻译 / 解释”两个选项；点击后结果在选词附近的浮窗中显示。解释为中文短解释，不保存知识卡。此操作只发送你主动选中的文字到 DeepSeek，不发送文章标题、附近段落或其他网页内容。按 Esc 或点击关闭按钮可关闭浮窗。
