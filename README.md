# 译读

一个面向英文技术文章的 Chrome 右侧边栏翻译扩展。原网页保持不变；滚动原文时，右侧译文会同步跟随。译读按阅读位置渐进翻译标题、各级标题、正文、列表和引用，并在中文侧保留加粗、下划线、链接、强调及行内代码等语义格式。翻译结果缓存在当前浏览器中。右侧栏提供中文翻译、AI 总结和固定译法库三个页签。表格、多列卡片和轮播组件不在右侧拆散翻译，仍完整保留于原网页。

## 本地使用

1. 打开 `chrome://extensions`，启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本项目目录。
3. 打开扩展详情页的“扩展程序选项”，填写 DeepSeek API Key。
4. 进入英文文章页面，点击工具栏中的扩展图标，Chrome 会在右侧打开译读。

API Key 仅保存在当前浏览器的本地扩展存储中。图片、图表、视频和交互组件保留在原网页，不进行 OCR 或复制翻译。

## 划词翻译与解释

在原网页中选中英文，右侧对应的整段译文会以暖色底标识；清除选区后恢复原样。复杂模块不在右侧翻译，也不会出现对应标识。选词时会出现“翻译 / 解释 / 固定译法”三个选项；点击后结果在选词附近的浮窗中显示。解释为中文短解释，不保存知识卡。翻译与解释只发送你主动选中的文字到 DeepSeek，不发送文章标题、附近段落或其他网页内容。按 Esc 或点击关闭按钮可关闭浮窗。

## 固定译法

选中英文短词或短语，点“固定译法”，输入希望沿用的译法并保存。用户确认的译法保存在当前浏览器的扩展存储中，跨文章优先于 AI 临时抽取的术语；再次保存同一英文可更新译法。右侧已翻译且包含该词的段落会保留旧内容并自动重翻，完成后更新缓存；其他文章中只有包含该词的旧段落缓存会在下次阅读时失效。选中文字的“翻译 / 解释”仍是实时请求，不会直接替换右侧整段译文。


## AI 总结

打开 AI 总结页签后，扩展按文章原有大章节逐模块调用已配置的 DeepSeek 模型，生成中文模块标题、模块概述和关键点，并缓存在当前浏览器中；再次打开相同内容可直接使用缓存。章节过长时会拆成连续部分，表格、轮播等复杂模块不发送。离开总结页签后不会继续发起后续模块请求，失败的模块可单独重试。

总结请求只发送文章标题、当前模块标题与正文到 DeepSeek，不发送网页 URL 或用户固定译法；URL 仅在浏览器本地用作缓存键。中文翻译的原有请求方式保持不变。

## 固定译法库页签

在侧栏中可以查看自己保存的固定译法，也可以添加、编辑或删除。原网页选词保存的译法会进入同一列表。更新或删除后，当前文章中包含该词的已翻译段落会重新翻译，其他文章中相关旧缓存会失效。
