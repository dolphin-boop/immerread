译读设置

粘贴 API 密钥后自动保存，仅保存在当前浏览器中。

AI 服务

译读使用 DeepSeek 模型生成导读、翻译正文和固定译法。创建 DeepSeek API 密钥。

使用 AI 功能时，DeepSeek 会收到网页正文内容。保存前请查看 DeepSeek 的服务条款和价格。

当前默认 deepseek-flash（DeepSeek-V4.1-Flash），也可填 deepseek-v4-pro。

已默认填入官方地址 https://api.deepseek.com；使用中转或代理时改为对应的 OpenAI 兼容地址（不需要 /chat/completions 后缀）。

本地缓存

译文和导读缓存在当前浏览器中：按文章网址保存，正文、格式、模型或固定译法变化时自动失效；最多保留 20 篇文章、30 天。想让某篇文章重新翻译，清除缓存后重新打开即可。
